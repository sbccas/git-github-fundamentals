The syllabus

Five units. One clear path.

From “what is version control?” to your first pull request. Each unit ends with missions and a quiz, and your progress is saved on this device.

How you’ll learn

Read a little. Type a lot.

Every topic follows the same loop, so you always know what comes next.

  1. 01

    Read

    Short lessons with everyday analogies and clear diagrams.

  2. 02

    Try

    Run each command in a real Git terminal and watch the graph change.

  3. 03

    Mission

    Solve a story problem from the Amroli Canteen team. Earn XP and badges.

  4. 04

    Quiz

    Check yourself with instant feedback and an explanation for every answer.

Real Git, in your browser

Not a video and not a fake. The terminal runs a real Git engine, so commits get real hashes, branches really branch, and merges really conflict.

$ git switch -c feature-menu
Switched to a new branch 'feature-menu'

See every command

A live commit graph redraws as you type. Slide through time to see your files at any commit.

Made for phones

A touch key bar, big buttons and a layout that fits a small screen. Install it to your home screen.

XP, levels & badges

Missions and quizzes earn XP. Collect a badge for every unit — and one for crushing your first conflict.

Find anything fast

Press Ctrl K or / to jump to any lesson, command or page.

Your story

Meet the Amroli Canteen team

Four BCA final-year students are building a canteen pre-order app. Lost files, broken code, conflicting edits — they hit every real problem, and you help them solve it with Git.
