How this site works

  • Real Git in your browser. The Playground and Missions run real Git (isomorphic-git) on a file system stored in your browser (LightningFS). The "GitHub" in the Playground is a practice copy in your browser; nothing is sent to github.com.
  • Private by design. No accounts, no tracking, no cookies, no analytics.
  • Open source. Built with Vite and published with GitHub Pages from github.com/sbccas.
  • For faculty. Slides, session plans and the faculty handbook are in Teach.
