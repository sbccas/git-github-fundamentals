# SYBCA AI 2026 — Class Wall 👋

Welcome to the class wall of the **Git & GitHub Fundamentals** certificate course (SBCCAS, Amroli).
Every student adds **one file** here through a **pull request** — your first contribution to someone else's repository!

## Your task (Remote session · Saturday 31 October · Part C)

1. **Fork** this repository: click **Fork** (top right) → **Create fork**.
2. In **your fork**, add a new file named with your **roll number**, for example `541.md`
   (on GitHub: **Add file → Create new file**; or clone your fork and use `git add`, `git commit`, `git push`).
3. Put this in the file:

   ```markdown
   # Your Full Name
   - Roll no: 541
   - GitHub: @your-username
   - My AI project: https://github.com/your-username/your-project
   - One line about it: …
   ```

4. Commit with a clear message, for example `Add 541 – Your Name`.
5. Open a **pull request** to `sbccas/sy-ai-2026-wall` (**Contribute → Open pull request**). Title: `541 – Your Name`.
6. Copy the pull request link and paste it on the course site:
   **Your account → Remote session → Part C**.

## Rules

- Add **only your own file** — do not change anyone else's file or this README.
- Be kind and professional: this repository is public.
- Never paste passwords, API keys or phone numbers here.

Faculty review and merge the pull requests. 🎉
