## Appendices {#appendices}

### A. Course at a glance {#app-glance}

| Unit | Sessions | Key commands | Practice | Badge |
|---|---|---|---|---|
| 1 · Version control | 1–2 | `config`, `help`, `--version` | M-01, M-02, L-01 | 🧭 Version Control Explorer |
| 2 · Getting started | 3–6 | `init`, `status`, `add`, `commit`, `remote`, `push`, `clone`, `fetch`, `pull` | M-03 – M-07, Unit 2 lab | 🚀 Repository Launcher |
| 3 · Branching | 7–9 | `branch`, `switch`, `checkout`, `merge`, `branch -d` | M-08 – M-11, conflict game, Unit 3 lab | 🌿 Branch Master · ⚔️ Conflict Crusher |
| 4 · Advanced | 10–12 | `log`, `show`, `diff`, `stash`, `tag`, `restore`, `reset`, `revert` | M-12 – M-15, time travel, Unit 4 lab | 🕵️ History Detective · ⏳ Time Traveller |
| 5 · GitHub | 13–14 | issues, pull requests, forks, `upstream` | L-02 – L-04 | 🤝 Open Source Collaborator |
| Assessment | 15 | all | practical, self-check, showcase | 🏆 Course Complete |

### D. Further reading for faculty {#app-reading}

- **Pro Git** (Scott Chacon & Ben Straub), free online at git-scm.com/book: the standard reference; chapters 1–3 and 6 match this course.
- **GitHub Docs** (docs.github.com): repositories, issues, pull requests, forks.
- **GitHub Skills** (skills.github.com): free interactive GitHub exercises for students who finish early.
- **Learn Git Branching** (learngitbranching.js.org): visual branching puzzles; good extension for Unit 3.
- **Git reference manual** (git-scm.com/docs): the same pages as `git help <command>`.
