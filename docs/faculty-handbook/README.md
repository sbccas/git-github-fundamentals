# Faculty Handbook — Git & GitHub Fundamentals

A book-style companion for faculty. The [faculty guide](../faculty-guide.md) explains **how to run** each session;
this handbook covers **what to know** before you teach it. It is also published on the course site at `/teach/handbook/`
(with a print / save-as-PDF button).

| File | Contents |
|---|---|
| [`00-story-bible.md`](00-story-bible.md) | The Amroli Canteen story: project, cast, story arc across all units, other story settings, storytelling tips |
| [`01-unit-1.md`](01-unit-1.md) | Chapter 1 — Introduction to Version Control |
| [`02-unit-2.md`](02-unit-2.md) | Chapter 2 — Getting Started with Git |
| [`03-unit-3.md`](03-unit-3.md) | Chapter 3 — Branching and Merging |
| [`04-unit-4.md`](04-unit-4.md) | Chapter 4 — Advanced Git Commands |
| *05-unit-5.md* | Chapter 5 — Introduction to GitHub *(Milestone 5)* |

Every chapter follows the same structure: learning outcomes · the story episode · the ideas in depth · more story examples ·
board diagrams · questions students ask · misconceptions · self-check for faculty · 10-minute recap.

Markdown extras used here (rendered on the site, readable on GitHub): `:::tip` boxes, `{#id}` heading anchors,
and ```` ```terminal ```` blocks where `$` lines are commands.
