## 3. Accuracy fixes (do not repeat these from the reference)

| Reference shows | Problem | We do |
|---|---|---|
| Hashes like `9e8f7g6`, `5h4i3j2` | Not valid hex — Git hashes use 0–9 and a–f only | Use real hashes from our terminal |
| `git init` → "Initialized empty Git repository in .git/" | Real output shows the full path | Real output |
| `git reset --soft HEAD~1` → "Unstaged changes after reset" | That message comes from `--mixed`; `--soft` prints nothing | Show correct output per mode |
| `git stash pop` → "Dropped stash@{0} — your changes are back!" | Invented message | Real output: status + `Dropped refs/stash@{0} (<hash>)` |
| `git push` → "main → main ✓" | Real Git prints `main -> main` | Real output |
| `git status` → "Untracked files: login.py, styles.css" on one line | Real output lists files on separate indented lines with hints | Real output |
| Uses `checkout <file>` only for discarding changes | Fine for syllabus, but modern Git recommends `restore` | Teach both, explain the relationship |

## 4. Design notes from the reference (for comparison only)

The reference uses a light theme (indigo `#6366f1` primary, slate text) with Space Grotesk / Inter / Fira Mono fonts, emoji section icons,
numbered step cards, comparison tables and coloured callouts (tip / warning / insight). We keep the **component ideas**
(step cards, comparison tables, callouts) but use our own dark futuristic design system (PRD §10).
