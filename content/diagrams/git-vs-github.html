Git a tool

💻 Installed on your computer
  • Tracks every change in a folder
  • Works offline
  • Free, open source (2005, Linus Torvalds)
  • Commands: init, add, commit, log…

GitHub a website

☁️ github.com
  • Stores Git repositories online
  • Needs the internet
  • Adds teamwork: issues, pull requests, forks
  • Your public developer portfolio

Git works without GitHub. GitHub needs Git. Similar sites: GitLab, Bitbucket.
