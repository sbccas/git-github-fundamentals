## Practical test rules

- Work in **Git Bash** on the lab PC (or the Playground if the network fails)
- Set your identity **locally** in the exam repository
- Clear commit messages count
- Submit your **GitHub repository URL** at the end

---
## Each task is scored

| Score | Meaning |
|---|---|
| **2** | correct result, correct commands, clean history, clear messages |
| **1** | correct result, but messy history or unclear messages |
| **0** | not done or wrong result |

## Practical test

Read every task first. Run `git status` often. Ask Git for help: `git <command> -h`.

Notes:
Press T for 60 minutes. Walk around but don't help with commands; you may help with lab PC or network problems.
